# React Native assignment — Mystery Watch

Build a standalone mobile app for discovering and opening mystery boxes containing watches.

Users should be able to browse boxes at different prices, explore their possible contents, purchase using a virtual balance, and manage their collection of won watches.

The **scrollable catalogue must display boxes as real-time rendered 3D models**, rather than static images or prerecorded videos.

The opening experience is the centerpiece: users interact with a **real-time 3D box**, inspect it, and open it through an animated reveal. Make the experience feel cohesive with the rest of the app.

Use **React Native and TypeScript**. You choose the architecture, libraries, visual design, and interactions. Use mock data and an asynchronous API simulation that you control.

We provide a 3D box model with separate movable parts, documentation describing its structure, and watch images. The model contains no prebuilt animations; you design and implement the interaction and opening animation.

Make your own decisions about the behaviors and technical considerations needed to turn this description into a polished, dependable mobile experience.

**Submit the source code.**
